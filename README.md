# Windows 右鍵簡繁檔名轉換器

Windows 檔案名稱簡體中文／繁體中文雙向轉換工具。

## 下載

請到 [Releases](https://github.com/he02329923/chinese-filename-tool/releases/latest) 下載最新版本的 `ChineseFilenameTool.exe` 或 ZIP 壓縮檔。

## 使用方式

1. 下載並雙擊 `ChineseFilenameTool.exe`。
2. 按「安裝這個工具」。
3. 在檔案或資料夾上按右鍵。
4. 選擇「轉換檔名為繁體中文」或「轉換檔名為簡體中文」。

支援檔案與資料夾，會保留副檔名，不會修改檔案內容。遇到同名檔案時會自動跳過。

## 移除工具

再次開啟 `ChineseFilenameTool.exe`，按「刪除這個工具」即可移除右鍵選單。EXE 檔案可再手動刪除。

Windows 11 如果看不到選項，請先選擇「顯示更多選項」。

## 轉換方式

程式使用 Windows 內建中文轉換功能，並補充常見詞彙對照，例如「軟件／軟體」和「文件／檔案」。目前不是完整 OpenCC 詞庫。
